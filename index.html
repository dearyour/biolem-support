시간의무덤은 사진과 글, 다녀온 장소를 모으는 개인 기록 앱입니다. 앱 안에서는 biolem이라는 이름을 사용합니다.

문의하기

로그인, 사진 업로드, 기록 확인 또는 개인정보에 관한 문의를 보내주세요.

kimyh2725@icloud.com

기기 종류, iOS 버전, 앱 버전과 문제가 생긴 순서를 알려주시면 확인에 도움이 됩니다. 비밀번호나 인증 코드는 보내지 마세요.

처음 사용하는 방법

  1. 이메일 또는 앱에서 제공하는 소셜 로그인으로 시작합니다.
  2. 아래의 +에서 장소를 검색하거나 지도에서 위치를 선택합니다.
  3. 제목, 날짜, 글과 사진을 추가해 장소 기록을 저장합니다.
  4. 기록 · 지도 · 마이에서 남긴 순간을 다시 확인합니다. 마이의 내 사진과 글에서는 날짜에 구애받지 않고 기록을 찾을 수 있습니다.

자주 묻는 질문

기록은 어디에 저장되나요?

사진을 포함한 장소 기록과 프로필은 계정 서버에 저장됩니다. 별도로 작성한 생각·글귀, 가고 싶은 장소, 화면 설정은 현재 기기에 보관됩니다. 기기에만 저장된 정보는 다른 기기와 자동으로 동기화되지 않습니다.

사진이나 위치를 사용할 수 없어요.

iPhone 설정에서 앱의 사진·위치 접근 권한을 확인해 주세요. 위치 권한을 허용하지 않아도 장소를 검색하거나 지도에서 직접 선택할 수 있습니다. 로그인, 장소 검색과 서버에 저장된 기록 확인에는 인터넷 연결이 필요합니다.

다른 기기에서 기록이 안 보여요.

처음 사용한 것과 같은 로그인 방식과 계정을 선택했는지 확인해 주세요. Apple의 이메일 가리기로 가입한 계정은 평소 사용하는 이메일 계정과 다를 수 있습니다. 기기에만 저장된 생각·글귀와 가고 싶은 장소는 자동으로 옮겨지지 않습니다.

기록이나 계정 정보를 삭제하고 싶어요.

장소 기록과 생각·글귀는 해당 기록의 상세 화면에서 삭제할 수 있습니다. 계정 전체, 업로드된 원본 사진 또는 관련 개인정보의 삭제를 원하면 문의 이메일로 요청해 주세요. 계정 확인 후 삭제 대상과 처리 결과를 안내합니다. 기기에만 보관된 정보는 사용하는 기기에서도 직접 삭제해 주세요.

개인정보와 외부 서비스

앱이 처리하는 정보, 저장 위치, 지도·장소 서비스에 관한 내용은 개인정보처리방침에서 확인할 수 있습니다.
