개인정보처리방침

김용희(Yonghee Kim)는 시간의무덤 서비스를 운영하며, 아래와 같이 개인정보를 처리합니다.

최종 수정: 2026년 10월 2일 · 대상: iOS 앱 1.0

1. 수집하는 정보와 이용 목적

계정 및 프로필
이메일 주소, 이름·닉네임, 프로필 사진, 로그인 방식, 사용자 식별자와 인증 정보를 계정 생성·로그인·프로필 표시·계정 보호에 사용합니다. 이메일 가입 비밀번호는 서버에서 해시 처리하여 저장합니다. Apple 로그인 시 Apple이 제공하는 사용자 식별자와 이메일(이메일 가리기 주소 포함), 사용자가 제공한 이름을 처리합니다. 카카오 로그인 시 카카오가 제공하는 이메일과 프로필 정보를 처리합니다.
장소 기록과 사진
사용자가 저장한 제목, 글, 방문 날짜, 장소 주소와 좌표, 평점, 사진 및 기록 북마크를 계정에 연결하여 서버에 저장합니다. 기록 목록·상세·지도·달력·보관함 기능을 제공하는 데 사용합니다.
사진에서 가져온 날짜와 위치
사진에서 기록을 시작하면 사용자가 직접 선택한 사진에 기록된 날짜와 위치 정보를 기기에서 읽어 방문 날짜와 장소를 미리 채우는 데 사용합니다. 촬영 날짜가 없으면 사진 보관함의 날짜 또는 오늘을 대체값으로 안내합니다. 장소 이름을 확인하기 위해 선택한 사진의 좌표와 사용자가 지도에서 고른 좌표를 Google 주소 변환 서비스로 전달합니다. 날짜와 장소는 저장 전에 수정할 수 있습니다. 앱이 전체 사진 보관함을 자동 분석하지 않습니다. 이 사진으로 계속을 누르면 선택한 사진의 업로드용 사본이 계정 서버로 전송됩니다. 기록을 저장하기 전 업로드된 사본이므로 이후 작성을 취소해도 서버에 남을 수 있습니다. 사진 보관함의 원본은 수정하지 않습니다.
위치와 장소 검색
사용자가 위치 접근을 허용하면 정확한 위치 또는 허용된 수준의 대략적인 위치를 현재 위치 표시와 주변 장소 검색에 사용합니다. 검색어, 선택한 장소 및 좌표가 Google 또는 카카오의 지도·장소 서비스로 전송될 수 있습니다. 장소 기록에 저장한 좌표와 주소는 해당 기록과 함께 보관됩니다.
지도 이용 및 기술 정보
Google Maps SDK는 기기 식별자, 지도 기능 이용 정보, 충돌·성능 정보 및 기타 기술 정보를 지도 제공과 분석을 위해 수집합니다. SDK의 개인정보 명세에 따라 기기 식별자와 일부 기술 정보는 식별자에 연결될 수 있고, 충돌·성능·상호 작용 진단 정보는 사용자 신원에 연결되지 않는 형태로 수집됩니다. 외부 서비스에 요청할 때 IP 주소와 요청 정보가 해당 제공업체에 전달될 수 있습니다.
고객 문의
문의 시 보낸 이메일 주소, 문의 내용과 사용자가 첨부한 정보를 문제 확인, 답변 및 개인정보 관련 요청 처리에 사용합니다.

2. 계정 기록과 기기의 임시 보관

타임캡슐의 제목·편지 원문·작성 시각·열 날짜·개봉 시각·답장과 저장 시각, 원래 장소 기록의 식별자를 계정에 연결하여 서버에 저장합니다. 장소 없는 생각·글귀와 출처·날짜·북마크, 가고 싶은 장소의 이름·주소·좌표·저장 시각도 같은 계정의 원본으로 보관합니다. 같은 계정으로 다른 기기에서 로그인하면 서버에 저장된 기록을 다시 확인할 수 있습니다.

새 기록은 HTTPS로 전송하고 서버에서 암호화하여 보관합니다. 다른 사람에게 공개하지 않으며 종단간 암호화 서비스로 제공하는 것은 아닙니다. 예전 기기 기록은 해당 계정의 서버 저장을 확인한 뒤 기기에서 정리합니다. 이전 편지 백업은 새 기록에 한 번 옮기며 수동 백업·복원 화면은 제공하지 않습니다.

전송하지 못한 작업, 서버와 내용이 다르거나 이관에 실패한 예전 원문은 손실을 막기 위해 기기 보안 저장소에 계정별로 남습니다. 앱의 안내에서 내용을 확인·내보내기하거나 연결 후 다시 시도할 수 있습니다. 서버 저장이 확인되기 전에 앱을 삭제하거나 기기를 교체하면 해당 기기에만 남은 자료를 잃을 수 있습니다. 로그아웃만으로 전송 대기 자료가 삭제되지는 않습니다. 화면 설정과 마지막으로 읽은 창작 문장의 ID는 기기에 저장합니다.

편지를 다른 사용자에게 보내거나 자동 알림·이메일로 발송하지 않습니다. 열 날짜는 기기에 설정된 날짜를 기준으로 한 읽기 약속이며 특정 날짜까지 암호로 잠그는 보안 기능이 아닙니다. 저장 장소의 검색·상세·외부 지도 기능을 사용하면 해당 장소 정보가 외부 지도 서비스로 전달됩니다.

사진 임시 파일

사진 선택·편집 과정에서 기기에 업로드용 임시 사본이 생길 수 있습니다. iPhone 앱의 마이 → 임시 사진 정리에서 이 임시 파일을 정리할 수 있습니다. 사진 보관함의 원본과 서버에 업로드한 사진은 이 작업으로 삭제되지 않으며, 앱이 표시한 모든 이미지 캐시가 함께 삭제되는 것은 아닙니다.

기존 기록에서 편지를 만드는 경우

사용자가 기존 장소 기록이나 생각·글귀에서 편지 만들기를 선택하면 해당 글을 편지 초안으로 가져옵니다. 사용자가 내용을 확인하고 보관을 확정한 편지는 내 계정에 별도 기록으로 저장됩니다. 원래 기록과 사진은 그대로 유지되며 사진을 편지에 복사하거나 봉인하지 않습니다. 장소에서 만든 편지를 열면 연결된 원래 기록으로 돌아갈 수 있지만, 원래 기록이 삭제된 경우에는 열 수 없습니다. 편지와 원래 기록은 따로 삭제할 수 있고, 하나의 삭제가 다른 하나의 삭제를 의미하지는 않습니다.

3. 외부 서비스와 정보 처리

  • Amazon Web Services: 계정, 장소 기록, 데이터베이스, 업로드된 사진, 타임캡슐·답장, 생각·글귀와 저장 장소의 서버 운영·저장에 사용합니다.
  • Google Maps Platform: 지도, 주소 변환, 장소 정보·사진·리뷰를 제공하며 위치, 검색 요청과 SDK 기술 정보를 처리합니다. Google 개인정보처리방침과 Google Maps 이용약관이 적용됩니다.
  • 카카오: 선택한 경우 카카오 로그인 및 장소 검색 요청을 처리합니다. 카카오 개인정보처리방침을 참고해 주세요.
  • Apple: Apple 로그인, iOS 권한·보안 저장소 및 앱 배포 기능을 제공합니다. Apple 개인정보처리방침을 참고해 주세요.

서버 인프라는 AWS 서울 리전을 사용합니다. Google·Apple 등 글로벌 제공업체는 각 정책에 따라 대한민국 외의 국가에서 정보를 처리할 수 있습니다. 외부 서비스 이용 시 해당 제공업체의 처리·보관 정책도 적용됩니다.

4. 광고와 추적

앱은 광고를 표시하거나 사용자 정보를 판매하지 않습니다. 다른 회사의 앱·웹사이트에서 수집한 정보와 결합하여 맞춤 광고를 제공하기 위한 추적 기능을 사용하지 않습니다. 지도 SDK의 서비스 제공·분석을 위한 데이터 처리는 위에 별도로 설명했습니다.

5. 보관과 삭제

계정 및 장소 기록은 서비스를 제공하고 사용자가 기록을 다시 확인하는 데 필요한 동안 보관합니다. 기록 상세 화면에서 개별 기록을 삭제할 수 있습니다. 개별 장소 기록 삭제가 업로드된 원본 파일과 모든 보관본의 즉시 삭제를 의미하지는 않습니다.

타임캡슐 상세의 편지 삭제는 서버의 원문과 답장을 함께 삭제합니다. 아직 열지 않은 편지도 삭제할 수 있습니다. 다른 기기는 다시 조회할 때 삭제를 반영합니다. 생각·글귀와 가고 싶은 장소도 앱에서 삭제할 수 있습니다. 오래된 요청으로 삭제한 기록이 다시 생기지 않도록 본문이 없는 삭제 표시와 작업 식별자를 계정이 유지되는 동안 보관합니다. 구버전 앱이 만든 예전 백업 사본은 별도 자료이며, 계정 삭제 시 함께 정리됩니다.

계정 전체 삭제는 앱의 마이 → 계정 삭제 → 계정 삭제하기 → 영구 삭제에서 요청합니다. 계정·프로필, 장소 기록과 업로드 사진, 북마크, 타임캡슐·답장·예전 백업, 생각·글귀·저장 장소와 삭제 표시·작업 기록을 서버에서 삭제하고 요청 기기의 전송 대기 자료도 정리합니다. 휴대폰 사진 보관함의 원본은 삭제하지 않습니다. 기기 정리에 실패하면 앱에서 재시도를 안내합니다.

다른 기기에 아직 전송하지 않은 예전 원문이나 임시 자료는 원격으로 지워지지 않으므로 해당 기기에서도 정리해주세요. 서버 계정 삭제 후에는 그 계정의 토큰으로 자료를 읽거나 새로 저장할 수 없습니다.

앱에 접근할 수 없거나 별도의 개인정보 삭제 요청이 있으면 아래 연락처로 문의할 수 있습니다. 본인 확인 후 요청 대상과 필요한 보관 사유를 확인하여 처리하고 결과를 안내합니다. 법령에 따른 보관 의무가 있는 정보는 해당 의무의 범위에서 보관합니다. 외부 서비스가 별도로 처리한 정보는 해당 서비스의 정책과 권리 행사 절차를 따릅니다.

6. 사용자의 선택과 권리

사용자는 개인정보의 열람·정정·삭제 및 처리 정지를 문의 이메일로 요청할 수 있습니다. 요청 처리에 필요한 범위에서 계정 확인을 요청할 수 있습니다. 비밀번호나 인증 코드는 요청하지 않습니다.

iPhone 설정에서 사진과 위치 접근 권한을 변경하거나 철회할 수 있습니다. 선택적 권한을 거부하면 해당 기능이 제한될 수 있으며, 위치 권한 없이도 장소 검색이나 지도에서 직접 위치를 선택할 수 있습니다.
